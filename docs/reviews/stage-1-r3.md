## Итог

Измерительная часть итерации 4 надёжна. По артефактам `results/stage-1/iter4/` 4597 из 4600 повторов валидны. Во всех 184 парных кейсах исход однозначен: 20/20 одного исхода. 174 кейса, общие с `iter3`, дали те же исходы. Контроль K2 = 0, решение G1 не записано агентом. Этап не принимается из-за одного MAJOR. Новое утверждение ADR-006 и отчёта G1 «SQL `INSERT OVERWRITE` не передаёт опции записи и конфликтов данных не даёт» противоречит Spark 4.0.1 на стенде.
