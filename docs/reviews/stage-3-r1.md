- **Повторяемый набор управляемых операций:** несовпадение хотя бы одного intent/seed/footprint. Проверка может это получить; unit с другим seed даёт различие,11 элементов двух полноразмерных S0 реально совпали.
- **Учёт стоимости:** пропавшая подготовка, неполная стадия, несоответствие UI или сумма выше приложения. Для этих случаев есть падающие условия и ненулевые измерения; источник CPU остаётся Spark executorCpuTime, не полный CPU процесса.
- **Инварианты и эффекты:** лишняя/пропавшая строка, лишняя версия, строка проигравшей операции, снимок вне линии, включение непрочитанного append в эффект. - **Ограниченная история:** upper peak>1452 или R вне измеренного интервала. Проверка получила оба отказа на R600 и правильно отвергла его. Для утверждений о времени телеметрии и фактической частоте проверка отсутствовала: нынешний невалидный случай уже присутствует в экспорте, но94 PASS его не обнаружили. Для максимальных байтов checker способен увидеть превышение только при совпадении с sample, поэтому гипотеза о всех промежуточных состояниях пока не проверена. Это MAJOR по обязательным условиям этапа, а не подтверждение ложного отрицательного результата о CAPL.
- **Работа переноса:** разрешённый инструмент не исполнился либо запрещённый изменил файлы/тег. Нативный verifier проверяет и hook exit, и состояние файлов; такие результаты привели бы к отказу. Smoke роли не используется как научная проверка этапа3.
