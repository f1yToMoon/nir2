Этап: $ARGUMENTS

## 0. Подготовка

1. Прочитай `AGENTS.md`, `docs/REVIEWER.md`, раздел этапа в `tz/06_implementation_plan.md`, отчёт этапа (если есть) и **все** ревью этапа `docs/reviews/stage-<N>-r*.md`.
2. Если последнее ревью этапа — `CHANGES_REQUESTED`, твоя задача в этой итерации — закрыть **все** его замечания. Составь список задач по ID замечаний (TaskCreate).
3. Если ревью ещё не было — составь список задач по плану этапа.

## 1. Реализация

- Работай по плану этапа и чек-листу этапа из `docs/REVIEWER.md` §4: это критерии, по которым тебя будут проверять.
- Не ослабляй проверки и пороги, чтобы они прошли (P8, P13). Если проверку трудно реализовать — чини реализацию.
- Утверждения о поведении Iceberg/Spark подтверждай по `third_party/iceberg-src` (`bash scripts/fetch_iceberg_src.sh`), со ссылкой `файл:строка`.
- Коммить по логическим шагам.

## 2. Самопроверка перед ревью

- Пройди общий чек-лист и чек-лист этапа из `docs/REVIEWER.md` сам.
- Обнови `docs/stage-<N>-report.md`: раздел «Ответы на ревью» — по каждому ID замечания: что сделано, где (файл, коммит), каким числом подтверждено. Если не согласен с замечанием — опровержение с доказательством.
- Обнови `docs/CHANGELOG.md`. Закоммить.

## 3. Ревью

- Вызови скилл `/review <N>` (субагент `stage-reviewer`).
- `CHANGES_REQUESTED` → вернись к шагу 1 с новыми замечаниями.
- Не более **3 раундов ревью за один запуск** этого скилла. После третьего `CHANGES_REQUESTED` — остановись и сообщи автору: какие замечания не удаётся закрыть и почему.

## 4. Завершение

- `PASS` / `PASS_WITH_NOTES`, этап **без** контрольной точки (не 1 и не 4): поставь тег `git tag stage-<N>` (хук проверит ревью), `git push && git push --tags`. MINOR-замечания перенеси в задачи следующего этапа. Сообщи автору итог и **остановись**. Следующий этап — только по команде автора `/stage <N+1>`.
- `PASS` / `PASS_WITH_NOTES`, этап **с** контрольной точкой (1 → G1, 4 → G2): напиши `docs/gate-G<1|2>-report.md` по шаблону с рекомендацией, поле «Решение автора» оставь пустым, закоммить, `git push`, **остановись** и попроси автора принять решение. Тег ставится только после решения автора (хук проверит).

Никогда не отмечай «Решение автора» сам и не переходи к следующему этапу без команды автора.
